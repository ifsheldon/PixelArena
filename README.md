# Semantic Segmentation / Face Parsing with Multimodal LLMs

## Usage

Setup project:

1. Install `uv`: https://docs.astral.sh/uv/getting-started/installation/
2. Run `uv sync` to install dependencies.
3. Run `uv run poe setup-frontend` to install frontend dependencies.

Run frontend: `uv run poe run-frontend`

## Eval Set

A random subset (500 images) of the Celeb-A dataset is used for evaluation.

- Images: `eval-set/celeb/images`, `512x512`
- Images (150): `eval-set/celeb/images-150`, `512x512`, a subset (150) of the images, only used for GPT-Image-1 since it's too expensive
- Reference masks: `eval-set/celeb/masks-512`, `512x512`
- Upscaled reference masks: `eval-set/celeb/masks-1024`, `1024x1024`

Test results should be saved in `test/` directory. For Gemini and GPT generated masks, the naming convention is `<id>.mask.[0-2].[raw.jpeg|pred.png]`. `[0-2]` is attempt index (total 3 attempts). `raw.jpeg` means the colorful jpeg generated by Gemini/GPT, `pred.png` means the P-mode png converted from the colorful jpeg.
